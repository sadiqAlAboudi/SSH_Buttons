2 {{.T.section_users}}

{{if eq .Lang "ar"}}

يدعم النظام نظام صلاحيات متعدد المستخدمين (RBAC) مع نوعين من الأدوار:

  • admin: صلاحيات كاملة: تشغيل الأزرار، تعديل وحفظ config.yml مباشرة في المتصفح، وإعادة تحميل الإعدادات.
  • operator: تشغيل أزرار الأوامر المصرح بها وعرض النتائج فقط (دون الوصول لمحرر الإعدادات).

تدعم كلمات المرور كل من النص الصريح (Plaintext) ورموز التشفير المؤمنة Bcrypt (التي تبدأ بـ $2a$ أو $2b$).

{{else}}

Role-Based Access Control (RBAC) supports two distinct user privileges:

  • admin: Full access: execute commands, edit & save config.yml in the WebUI, and reload configuration.
  • operator: Limited to executing authorized action buttons and viewing output logs.

Passwords support both plaintext and secure bcrypt hashes (prefixed with $2a$ or $2b$).

{{end}}
YAML: users block
users: - user: "admin" pass: "adminpassword" role: "admin" - user: "operator1" pass: "$2a$10$N9qo8uLOickgx2ZMRZoMyeIjZAgcfl7p92ldGxad68LJZdL17lhWy" role: "operator"

3 {{.T.section_hosts}}

{{if eq .Lang "ar"}}

تُعرّف الأجهزة المستهدفة ضمن قسم hosts:. يدعم النظام خوادم Linux وأجهزة شبكات MikroTik ومحولات Cisco.

الحقلالنوعالوصف والاستخدام
hostمطلوبعنوان IP أو اسم النطاق للجهاز الهدف.
userمطلوباسم مستخدم تسجيل الدخول عبر SSH.
portاختياريمنفذ SSH (الافتراضي: 22).
key / key_pathاختياريمسار مفتاح SSH الخاص (نسبي أو مطلق).
pass / passwordاختياريكلمة مرور SSH في حال عدم توفر المفتاح.
pty: trueمهم للشبكاتتفعيل محاكي الطرفية التفاعلية (PTY Shell). مطلوب لأجهزة Cisco ومحولات الشبكة التي ترفض أوامر exec غير التفاعلية.
legacy_ciphers: trueمهم للأجهزة القديمةتفعيل خوارزميات التشفير وتبادل المفاتيح القديمة (Diffie-Hellman group1/14, 3DES, AES-CBC, ssh-rsa) لأجهزة Cisco Catalyst و RouterOS v6 القديمة.
insecure: falseاختياريإلزام التحقق من بصمة الجهاز عبر ملف known_hosts (افتراضياً: true لتسهيل العمل في الشبكات المحلية).
{{else}}

Target devices are registered under the hosts: map. The runner supports Linux servers, MikroTik RouterOS, and Cisco network switches.

FieldTypeDescription & Usage
hostRequiredIP address or hostname of the remote machine.
userRequiredSSH login username.
portOptionalSSH port (default: 22).
key / key_pathOptionalPath to private key file (relative to config or absolute).
pass / passwordOptionalSSH login password.
pty: trueNetwork EssentialEnforces interactive pseudo-terminal shell mode. Required for Cisco IOS and network switches that reject non-interactive 'exec' channels.
legacy_ciphers: trueLegacy GearEnables older DH (group1/14), 3DES, AES-CBC, and ssh-rsa algorithms for legacy Cisco Catalyst switches and RouterOS v6.
insecure: falseOptionalEnforces host key verification via known_hosts (defaults to true for homelab convenience).
{{end}}

4 {{.T.section_buttons}}

{{if eq .Lang "ar"}}

تُنظّم الأزرار داخل تصنيفات categories:. عند تحديد host: على مستوى التصنيف، يتم توريثه تلقائياً لجميع الأزرار داخله لتجنب التكرار.

الخاصيةالوصف والاستخدام
nameاسم الزر المعروض في الواجهة.
cmdالأمر المنفذ عبر SSH على الجهاز الهدف.
stdin / inputإدخال تأكيدي تلقائي للأوامر التي تطلب موافقة، مثل "y\n" لإعادة تشغيل MikroTik أو "\n" لموافقة reload في Cisco.
danger: trueيطبق اللون الأحمر ويلزم نافذة تأكيد قبل التنفيذ.
warning: trueيطبق اللون البرتقالي ويلزم نافذة تأكيد قبل التنفيذ.
styleلون مخصص: primary (افتراضي), secondary, success, warning, danger.
timeoutمهلة التنفيذ بالثواني (الافتراضي: مهلة الخادم 15 ثانية).
{{else}}

Buttons are grouped inside categories:. Specifying host: at the category level automatically cascades to every button inside it, keeping your configuration clean and DRY.

PropertyDescription & Usage
nameDisplay label on the button.
cmdCommand executed over SSH on the remote host.
stdin / inputAutomated confirmation input, e.g. "y\n" for MikroTik reboot or "\n" for Cisco reload confirm.
danger: trueApplies crimson styling and enforces a confirmation dialog before running.
warning: trueApplies amber styling and enforces a confirmation dialog before running.
styleCustom color: primary (default), secondary, success, warning, danger.
timeoutExecution timeout in seconds (default: server timeout 15s).
{{end}}

[confirm]' danger: true
