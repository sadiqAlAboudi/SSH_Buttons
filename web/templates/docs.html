المتغيرالقيمة الافتراضيةالوصف والتأثير

2 {{.T.section_users}}

{{if eq .Lang "ar"}}

يوفر النظام إدارة دقيقة لصلاحيات المستخدمين (RBAC) لدعم فرق العمل والعمليات:

  • admin (المدير): صلاحيات غير محدودة تشمل تشغيل الأوامر، تحرير وحفظ ملف config.yml مباشرة في المتصفح، وإعادة تحميل الإعدادات.
  • operator (المشغل): مقتصر على تشغيل أزرار الأوامر المصرح بها واستعراض سجلات المخرجات، مع حظر الوصول لصفحة التحرير.

تدعم كلمات المرور النصوص الصريحة للتجارب السريعة، وتجزئات Bcrypt المؤمنة (التي تبدأ بـ $2a$ أو $2b$) الموصى بها لبيئات الإنتاج.

{{else}}

Role-Based Access Control (RBAC) supports two distinct user privilege tiers:

  • admin: Full access: execute commands, edit & save config.yml in the WebUI, and reload configurations.
  • operator: Limited to executing authorized action buttons and viewing command outputs (cannot access editor).

Passwords support both plaintext (for local labs) and secure bcrypt hashes (prefixed with $2a$ or $2b$) for production environments.

{{end}}
YAML: users block
users: - user: "admin" pass: "adminpassword" role: "admin" - user: "operator1" pass: "$2a$10$N9qo8uLOickgx2ZMRZoMyeIjZAgcfl7p92ldGxad68LJZdL17lhWy" role: "operator"

3 {{.T.section_hosts}}

{{if eq .Lang "ar"}}

تُعرّف الأجهزة والخوادم في قسم hosts:. يتوافق النظام تماماً مع خوادم Linux وأجهزة شبكات MikroTik RouterOS ومحولات Cisco Catalyst.

الحقلالحالةالوصف والاستخدام
hostمطلوبعنوان IP أو اسم النطاق للجهاز الهدف.
userمطلوباسم مستخدم تسجيل الدخول عبر بروتوكول SSH.
portاختياريمنفذ SSH (الافتراضي: 22).
key / key_pathاختياريمسار مفتاح SSH الخاص (نسبي إلى مجلد الإعدادات أو مطلق).
pass / passwordاختياريكلمة مرور SSH في حال عدم استخدام المفاتيح الخاصة.
pty: trueأساسي للشبكاتتفعيل جلسة الطرفية التفاعلية (PTY Shell). ضروري لأجهزة Cisco ومحولات الشبكة التي ترفض قنوات exec غير التفاعلية.
legacy_ciphers: trueللأجهزة القديمةتفعيل خوارزميات التشفير وتبادل المفاتيح التراثية (Diffie-Hellman group1/14, 3DES, AES-CBC, ssh-rsa) لأجهزة Cisco القديمة و RouterOS v6.
insecure: falseاختياريإلزام مطابقة بصمة الخادم عبر ملف known_hosts (افتراضياً: true لمرونة التشغيل المحلي).
{{else}}

Target devices are registered under the hosts: map. The runner natively supports Linux servers, MikroTik RouterOS, and Cisco network switches.

FieldStatusDescription & Usage
hostRequiredIP address or hostname of the remote machine.
userRequiredSSH login username.
portOptionalSSH port (default: 22).
key / key_pathOptionalPath to private key file (relative to config or absolute).
pass / passwordOptionalSSH login password.
pty: trueNetwork EssentialEnforces interactive pseudo-terminal shell mode. Required for Cisco IOS and network switches that reject non-interactive 'exec' channels.
legacy_ciphers: trueLegacy GearEnables older DH (group1/14), 3DES, AES-CBC, and ssh-rsa algorithms for legacy Cisco Catalyst switches and RouterOS v6.
insecure: falseOptionalEnforces host key verification via known_hosts (defaults to true for homelab convenience).
{{end}}

4 {{.T.section_buttons}}

{{if eq .Lang "ar"}}

تُجمع الأزرار بصرياً داخل تصنيفات categories:. عند تحديد host: على مستوى التصنيف، يتم توريثه تلقائياً لجميع أزراره، مما يختصر التكرار ويسهل الصيانة.

الخاصيةالوصف والتأثير
nameنص التسمية المعروض على الزر في الواجهة.
cmdأمر الصدفة (Shell command) المنفذ عبر SSH على الجهاز الهدف.
stdin / inputإدخال تأكيدي تلقائي للأوامر التفاعلية، مثل "y\n" لإعادة تشغيل MikroTik أو "\n" لموافقة reload في Cisco.
danger: trueاختصار يطبق اللون القرمزي مع تفعيل نافذة تأكيد إلزامية قبل التنفيذ.
warning: trueاختصار يطبق اللون البرتقالي مع تفعيل نافذة تأكيد إلزامية قبل التنفيذ.
styleلون مخصص: primary (افتراضي), secondary, success, warning, danger.
timeoutمهلة التنفيذ بالثواني لهذا الزر (تتجاوز مهلة الخادم العامة).
{{else}}

Buttons are grouped inside categories:. Specifying host: at the category level automatically cascades to every button inside it, keeping your configuration clean and DRY.

PropertyDescription & Usage
nameDisplay label on the button.
cmdCommand executed over SSH on the remote host.
stdin / inputAutomated confirmation input, e.g. "y\n" for MikroTik reboot or "\n" for Cisco reload confirm.
danger: trueApplies crimson styling and enforces a confirmation dialog before running.
warning: trueApplies amber styling and enforces a confirmation dialog before running.
styleCustom color: primary (default), secondary, success, warning, danger.
timeoutExecution timeout in seconds (overrides global server timeout).
{{end}}
